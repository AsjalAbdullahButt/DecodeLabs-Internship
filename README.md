## 📁 Projects

### 🤖 Project 1 — Rule-Based Chatbot

A terminal-based chatbot built in pure Python with **no external dependencies**. Uses a dictionary-based intent matching system instead of if-elif chains, achieving O(1) average lookup time. Implements a clean REPL loop with input sanitization, graceful Ctrl+C handling, and a modular two-file architecture separating engine logic from I/O.

**Stack:** Python 3.8+ · No dependencies

### 📊 Project 2 — KNN Data Classification Pipeline

A complete, modular ML pipeline for classifying the Iris dataset using K-Nearest Neighbors. Covers the full workflow — data loading, stratified train-test split, StandardScaler preprocessing (without data leakage), hyperparameter tuning (k=1 to 20), and evaluation via accuracy, weighted F1, and a confusion matrix heatmap. Achieved **96.67% accuracy** on the test set.

**Stack:** Python · scikit-learn · pandas · numpy · matplotlib · seaborn

📄 **[View Full Documentation →](https://github.com/AsjalAbdullahButt/DecodeLabs-Internship/blob/main/Project%202/Data%20Classification/README.md)**

---

### 🧠 Project 3 — Tech Stack Recommender

A career path recommender that maps a user's skill set to the most suitable tech roles using TF-IDF vectorization and cosine similarity. Covers the full pipeline — skill ingestion with cold-start handling, TF-IDF corpus fitting, cosine similarity scoring across 15 job role profiles, top-N ranking, and session logging. Ships with both a CLI and a Streamlit web UI that supports light and dark mode.

**Stack:** Python · scikit-learn · Streamlit · pandas

📄 **[View Full Documentation →](https://github.com/AsjalAbdullahButt/DecodeLabs-Internship/blob/main/Project%203/Tech-Stack-Recommender/README.md)**
